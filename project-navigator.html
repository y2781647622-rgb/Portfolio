Path 02A / Interaction design

Library
Wayfinding.

A bilingual search journey that turns an unfamiliar call number into a sequence of understandable decisions.

Role
Interaction designer
Format
Web experience
Focus
Route, language, flow
Enter live site ↗

The tension

A call number can feel like a barrier before a search even begins.

The task was to make a library classification system feel approachable without reducing its logic or bilingual context.

Design move

Turn the search into a sequence of clues.

Each interaction answers one immediate question, gradually revealing how the route, shelf, and destination relate.

What I made

A path with a point of view.

A bilingual, game-like wayfinding experience that helps visitors move from a code to a place with confidence.
