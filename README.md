# Ways Through

Yang Shenghua's portfolio for human-centred design, systems thinking, and interactive worlds.

## Structure

- **Hero** — a concise positioning statement and route-based entry points.
- **Selected work** — three visible chapters: Worlds to enter, Paths to navigate, and Shared futures.
- **Method** — a compact Frame / Translate / Test interaction.
- **AI practice** — Language / Logic / Form, with tools as supporting evidence rather than the headline.
- **Project pages** — a consistent image-left, explanation-right layout with role, context, contribution, and direct project links.

## Files that define the site

- `index.html` — homepage
- `project-*.html` — five project overviews
- `site.css` — the only active stylesheet
- `site.js` — the only active interaction script

## Publishing

Upload the complete `portfolio-framework` folder to the GitHub Pages repository. Keep the relative paths unchanged. The Terra-Link deck is `1.pdf` and the website video is `assets/terralink-film-web.mp4`.
