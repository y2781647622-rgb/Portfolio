# Portfolio framework

A dark, responsive portfolio for a Human-Centred Design graduate. It prioritises project entry points, distinctive visual worlds, and concise evidence over résumé-style copy.

## Page structure

- **Live projects:** four direct GitHub Pages links, written directly into `index.html`.
- **Approach:** a compact three-part interaction: Frame, Translate, Verify.
- **Selected work:** two research-led projects with individual portfolio pages.
- **Personal index:** two interactive personal projects with individual portfolio pages.
- **AI practice:** the real Gemini → Codex → Hunyuan AI workflow.
- **About:** a short background statement only. The site intentionally has no résumé, email, contact form, or social-profile links.

## Project pages

- `project-streets.html` — When Streets Become Systems
- `project-navigator.html` — Narrative Navigator
- `project-abyss.html` — Abyss Kitchen
- `project-crossings.html` — Four Crossings of the Chishui River

Each page has one question, three short project signals, its own visual motion, and a link to the original live project.

## Motion principles

- Scrolling reveals sections gently; it never hides information.
- Hover effects give project cards a little physical response.
- Tabs change only one focused content panel at a time.
- All interactive controls work with a keyboard and respect reduced-motion preferences.
